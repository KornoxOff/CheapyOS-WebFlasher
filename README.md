# 🌐 CheapyOS Web Flasher

Flash **CheapyOS V4** sur ta carte ESP32 CYD en un clic depuis ton navigateur.

## 🚀 Utilisation

1. Ouvre **[le flasher](https://KornoxOff.github.io/CheapyOS-WebFlasher/)**
2. Clique sur **INSTALL**
3. Sélectionne le port COM de ta carte
4. Attends 1-2 minutes

## ⚠️ Prérequis

- Navigateur **Chrome, Edge ou Opera** (Firefox non supporté)
- Câble USB **data**
- Carte **ESP32-2432W328R (CYD)**

## 📦 Firmware

- **Version** : V4.0
- **Taille** : 4 MB
- **Source** : [github.com/KornoxOff/CheapyOS-V4](https://github.com/KornoxOff/CheapyOS-V4)
